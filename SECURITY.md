# Security Policy

## Supported Versions

| Version | Supported          |
| :---    | :---               |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of Findora seriously. If you believe you have discovered a vulnerability or security risk (such as command injection, path traversal, or unhandled IPC inputs), please report it responsibly.

### How to Report
1. **Do not create a public GitHub issue** for undisclosed security vulnerabilities.
2. Please submit a private advisory through GitHub's [Security Advisory tab](https://github.com/aadiur/Findora/security/advisories) or contact the project maintainer directly.
3. Include detailed steps to reproduce the vulnerability, including proof-of-concept scripts or input payloads where applicable.

### What to Expect
- **Acknowledgment**: Within 48 hours of receipt.
- **Assessment**: We will evaluate the report, verify the impact, and keep you informed.
- **Fix & Disclosure**: We will prepare and deploy a patch, and coordinate public disclosure.
